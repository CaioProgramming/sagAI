# Calendário de Conteúdo - sagAI (Revamp: Vídeo + Carrossel) 📅

Este calendário foi atualizado para focar em uma estratégia de **conteúdo complementar**:

- **Vídeos (Reels/Shorts/TikTok)**: Usados para atrair atenção, mostrar o "como é" (demo) e gerar
  entretenimento.
- **Carrosséis**: Usados para reter, educar sobre o "porquê" ou "como funciona" e gerar salvamentos.
- **Estratégia**: Um dia alimenta o outro. O vídeo gera curiosidade, o carrossel entrega o valor
  profundo.

**Frequência**: 3x por semana (Segunda, Quarta, Sexta)

## 🛠️ Lista de Assets Necessários (Checklist)

### Vídeos (Formato 9:16 - Vertical)

- [ ] **Trailer Geral**: Intro do app, cortes rápidos.
- [ ] **Feature Tours**: Vídeos de 15-30s focados em UMA feature (Wiki, Smart Fix, Criação).
- [ ] **Mood Edits**: Vídeos focados em "vibe" (Cyberpunk, Terror), com música.
- [ ] **Bastidores**: Gravações de tela "cruas" mostrando o processo real.

### Imagens/Design (Formato 4:5 ou 1:1)

- [ ] **Capas de Carrossel**: Títulos grandes, contraste alto.
- [ ] **Diagramas Explicativos**: Para os posts técnicos (IA, Estrutura).
- [ ] **Mockups do App**: Onde inserir os screenshots para ficar limpo.
- [ ] **Prints de Exemplo**: Histórias fictícias interessantes para ilustrar.

## 📝 Notas de Produção de Vídeo

1. **Gancho nos primeiros 3s**: O vídeo tem que prender visualmente ou com uma frase
   polêmica/curiosa imediatamente.
2. **Legendas**: Sempre legendado. Muita gente assiste no mudo.
3. **Áudio**: Use músicas em alta (trending) se possível, ou a trilha sonora do próprio app para
   imersão.
4. **Call to Action**: No final do vídeo, sempre apontar para a legenda ou pedir para baixar.
