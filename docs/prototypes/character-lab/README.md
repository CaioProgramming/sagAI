# Character lab

Terminal loop to tune the character blueprints without building the app. See the header of
`character_lab.py` for usage. Needs `firebase` (logged in), `python3` and a `GEMINI_API_KEY`
in the environment. The prompt is an approximation of the app's; confirm in the app before publishing.

Findings so far (hmg, Heroes, 2026-11-03) live in the commit history of the character-reviewer branch.
