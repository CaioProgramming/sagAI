✦ Sagas 1.19.1 — Google Play

🇺🇸 English

Deleting a saga used to haunt the next one you opened, so the details screen showed an error that belonged to a story that no longer exists. It stays gone now.

Deleting a message while the characters were still reacting to it could close the app. Now they just quietly lose interest. The chat input also got a solid background, so what you type no longer competes with the conversation behind it.

🇧🇷 Português

Excluir uma saga assombrava a próxima que você abria, e a tela de detalhes mostrava um erro de uma história que nem existe mais. Agora ela fica onde deve: no passado.

Apagar uma mensagem enquanto os personagens ainda reagiam a ela podia fechar o app. Agora eles só perdem o interesse, discretamente. E o campo de texto do chat ganhou um fundo sólido, então o que você digita não disputa mais atenção com a conversa atrás.
