Character rewards flow

Replaces the top island for character level-ups, medals and legacies. Everything earned since the last time the player was here opens as one full sheet, one step per achievement, grouped by character.

Queue built for this example
    When it opensOn the chat or home screen, after a milestone has closed and no image or book generation is running. In the background nothing is marked as told.
    OrderHighest level first. Per character: level, then medals, then legacy, then new bonds with other characters. The character avatar is always the largest element. One step per achievement, no row cap.
    Marked as toldOnly when the player reaches the last step or closes the sheet. If the app dies midway, the whole queue comes back.
    IslandNo longer used for these events. Tap the island preview in the phone to see what it does today is gone.

    Colors and corner radius are the real Remote Config values (snapshot v1113). Genre fonts are not embedded here, so titles use a system face.
